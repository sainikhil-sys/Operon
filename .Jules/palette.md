## 2024-10-05 - Proper usage of base-ui Tooltip and Screen Reader accessibility
**Learning:** In this project which uses `@base-ui/react`, composing a custom Button with TooltipTrigger requires using the `render={<Button>...</Button>}` pattern instead of typical Radix `asChild`. When providing a Tooltip for an icon-only button, it's essential to supply the `aria-label` to the interactive element being triggered (e.g. the Button rendered via TooltipTrigger) rather than relying on the TooltipContent. Further, setting `aria-hidden="true"` on the internal SVG prevents screen readers from duplicating or misreading the icon alongside the `aria-label`.
**Action:** Always use the `render={<Button aria-label="Description" />}` pattern for TooltipTriggers wrapping buttons and ensure internal SVGs have `aria-hidden="true"` to create robust, accessible screen reader experiences while avoiding TS type issues or invalid nested buttons.
