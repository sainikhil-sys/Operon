## 2026-09-30 - Accessible Notification Menus\n**Learning:** When adding ARIA labels to buttons containing dynamic content (like unread counts), the label should reflect the full state (e.g., 'Notifications, 3 unread') and all internal visual elements must be hidden with `aria-hidden='true'` to avoid redundant announcements.\n**Action:** Always check if a button's content is dynamic before assigning a static aria-label, and ensure all purely decorative or redundant visual elements inside an explicitly labeled container are hidden from screen readers.
