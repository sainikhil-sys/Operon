## 2025-02-14 - Accessibility & Focus States in Native Layout Buttons\n**Learning:** The native `<button>` elements in layout components (like the Topbar search and Sidebar command palette triggers) lack explicit focus-visible states and clear ARIA descriptions for screen readers, unlike the base `Button` component.\n**Action:** Add `focus-visible:ring-[#46D296] focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-offset-2 focus-visible:ring-offset-black` utilities and appropriate `aria-label`/`title` properties to native layout buttons to ensure keyboard a11y.
